Project Overview:

UMBC Cipher is a C++ encryption and decryption application designed to demonstrate object-oriented 
programming concepts through the implementation of multiple cipher algorithms. The project utilizes 
inheritance, polymorphism, and pointer-based class relationships to create a flexible and extensible
software architecture.


Skills Demonstrated:

Object-Oriented Programming
Class Hierarchies
Inheritance and Polymorphism
Utilization of pointers
Software Design and Architecture
Problem Solving in C++
